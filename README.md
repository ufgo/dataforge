# DataForge

DataForge is a visual game database and content editor designed for game designers and developers. It helps you easily structure, organize, and edit static game data (such as items, enemies, quests, and dialogue scripts) without dealing with the complexity of raw JSON files or messy Excel spreadsheets.

This repository hosts the source code for the official DataForge landing page and documentation site: **[ufgo.github.io/dataforge](https://ufgo.github.io/dataforge/)**.

---

* **Download:** You can download the latest prebuilt Windows installer (`.msi` or `.zip`) directly from the live website or download it from the [releases/](https://github.com/ufgo/dataforge/releases).
